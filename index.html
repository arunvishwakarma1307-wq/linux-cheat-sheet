📂 Git Commands

git init

📖 What it does
Creates a new Git repository in the current folder.

💡 When to use
When starting a new project that you want Git to track.

🖥 Example
git init

git clone

📖 What it does
Downloads an existing Git repository from GitHub to your computer.

💡 When to use
When you want to start working on an existing GitHub project.

💻 Example
git clone https://github.com/username/project.git

git status

📖 What it does
Shows the current status of your Git repository, including modified, staged, and untracked files.

💡 When to use
Before committing changes to check what has changed.

💻 Example
git status

git add .

📖 What it does
Stages all new and modified files for the next commit.

💡 When to use
After editing your project and before running git commit.

💻 Example
git add .

git commit -m

📖 What it does
Creates a new commit and saves your staged changes with a message.

💡 When to use
After using git add and when you're ready to save your changes.

💻 Example
git commit -m "Added login page"

git push

📖 What it does
Uploads your local commits to the remote GitHub repository.

💡 When to use
After creating a commit and when you want to update GitHub.

💻 Example
git push origin main

git pull

📖 What it does
Downloads the latest changes from the remote repository and updates your local project.

💡 When to use
Before starting work so your project has the latest code from GitHub.

💻 Example
git pull origin main

git log

📖 What it does
Displays the complete commit history of your Git repository.

💡 When to use
When you want to view previous commits, messages, authors, or commit IDs.

💻 Example
git log

git branch

📖 What it does
Lists all branches in the current Git repository and allows you to create new branches.

💡 When to use
When you want to view existing branches or create a new branch for a feature or bug fix.

💻 Example
git branch feature-login

git checkout

📖 What it does
Switches to another branch or restores files from a previous state.

💡 When to use
When you want to move to another branch or inspect older versions of your project.

💻 Example
git checkout main

git switch

📖 What it does
Switches from one Git branch to another using the newer Git command.

💡 When to use
When you want to move to another branch in modern versions of Git.

💻 Example
git switch main

git merge

📖 What it does
Combines changes from one branch into another branch.

💡 When to use
After completing work on a feature branch and merging it into the main branch.

💻 Example
git merge feature-login

git remote -v

📖 What it does
Displays the remote repositories connected to your local Git project.

💡 When to use
When you want to verify which GitHub repository your project is linked to.

💻 Example
git remote -v

git fetch

📖 What it does
Downloads the latest changes from the remote repository without merging them into your current branch.

💡 When to use
When you want to check the latest updates from GitHub before deciding to merge them.

💻 Example
git fetch origin

git reset

📖 What it does
Removes changes from the staging area or moves the repository back to a previous commit.

💡 When to use
When you accidentally staged files or want to undo recent commits before pushing.

💻 Example
git reset HEAD file.txt

git restore

📖 What it does
Restores a file to its previous state by discarding unwanted changes.

💡 When to use
When you want to undo changes made to a file before committing them.

💻 Example
git restore file.txt

git stash

📖 What it does
Temporarily saves your uncommitted changes without creating a commit.

💡 When to use
When you need to switch branches but don't want to commit your unfinished work.

💻 Example
git stash

git rm

📖 What it does
Removes a file from your Git repository and stages the deletion for the next commit.

💡 When to use
When you want to permanently delete a tracked file from your project and Git history.

💻 Example
git rm file.txt

🐳 Docker Commands

docker --version

📖 What it does
Displays the installed Docker version on your computer.

💡 When to use
To verify that Docker is installed correctly and check its version.

💻 Example
docker --version

docker pull

📖 What it does
Downloads a Docker image from Docker Hub or another container registry.

💡 When to use
Before running a container when the required image is not available on your computer.

💻 Example
docker pull nginx

docker run

📖 What it does
Creates and starts a new container from a Docker image.

💡 When to use
To run an application inside a new Docker container.

💻 Example
docker run nginx

docker ps

📖 What it does
Shows all currently running Docker containers.

💡 When to use
To see which containers are currently running.

💻 Example
docker ps

docker ps -a

📖 What it does
Shows all Docker containers, including running, stopped, and exited containers.

💡 When to use
To view every container and check its current status.

💻 Example
docker ps -a

docker images

📖 What it does
Displays all Docker images stored on your local computer.

💡 When to use
To check which Docker images are available before creating a container.

💻 Example
docker images

docker stop

📖 What it does
Stops a running Docker container gracefully.

💡 When to use
When you want to stop a running container without removing it.

💻 Example
docker stop my-container

docker start

📖 What it does
Starts an existing stopped Docker container.

💡 When to use
When you want to run a previously stopped container again.

💻 Example
docker start my-container

docker restart

📖 What it does
Stops and immediately starts a Docker container.

💡 When to use
When you need to quickly restart a container after making changes.

💻 Example
docker restart my-container

docker exec

📖 What it does
Runs a command inside a running Docker container.

💡 When to use
When you need to access or troubleshoot a running container.

💻 Example
docker exec -it my-container bash

docker logs

📖 What it does
Displays the log output of a Docker container.

💡 When to use
To check application output or troubleshoot container issues.

💻 Example
docker logs my-container

docker build

📖 What it does
Builds a Docker image from a Dockerfile.

💡 When to use
After creating or updating a Dockerfile for your application.

💻 Example
docker build -t my-app .

docker rm

📖 What it does
Removes one or more stopped Docker containers.

💡 When to use
To clean up containers that are no longer needed.

💻 Example
docker rm my-container

docker rmi

📖 What it does
Removes one or more Docker images from your computer.

💡 When to use
To free up disk space by deleting unused Docker images.

💻 Example
docker rmi nginx

docker compose up

📖 What it does
Starts all services defined in a Docker Compose file.

💡 When to use
When your application uses multiple containers such as a web server and a database.

💻 Example
docker compose up -d
